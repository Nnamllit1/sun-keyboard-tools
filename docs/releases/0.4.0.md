Download **SunKeyboardTools-Setup-0.4.0-x64.exe** and choose **Update or repair app**. Saved shortcuts, automatic startup, and the existing USBPcap installation are preserved.

- A narrower main window focuses on your key mappings, Save, and a compact remapping status. The raised key labels and purple accents remain; the three decorative header keys are removed.
- **Settings** now opens a separate window for startup, keyboard profiles, restoring defaults, and help.
- Activity counters move to a separate **Key Monitor**, available from Settings or the tray menu.
- Opening Key Monitor does not disable shortcuts. Select **Test keys without sending shortcuts** to test safely. Closing Key Monitor, including with Escape, ends test mode. Closing the main window also closes its utility windows and ends test mode while the app continues in the tray.
- Profile changes still protect unsaved mappings. Profiles with matching display names also show their file names.

The remapping backend and bundled driver are unchanged. Requirements remain Windows 10/11 x64 and an administrator account. USBPcap 1.5.4.0 has an [unresolved Windows 11 crash report](https://github.com/desowin/usbpcap/issues/146).

The app and installer remain unsigned. The original code has no selected license; USBPcap retains its upstream signature, matching source, and GPL/BSD licenses.
