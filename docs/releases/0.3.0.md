Download **SunKeyboardTools-Setup-0.3.0-x64.exe** and choose **Update or repair app** to upgrade. Saved shortcuts and the existing USBPcap installation are preserved.

- Refreshed settings window with a soft neutral background, purple accents, subtle panel shadows, and raised key labels inspired by the keyboard.
- Separate shortcut, connection, and live-activity panels make the current state easier to read.
- Clear unsaved-change and saved feedback; Save becomes available when a shortcut changes.
- Brief highlights identify the extra key most recently received by the app.
- Native editable dropdowns, keyboard navigation, and system high-contrast colors remain available. Longer profiles and shorter displays can scroll vertically.

The remapping backend and driver are unchanged. The graphical installer, repair, driver options, and uninstaller remain available from **Sun Keyboard Tools Setup** in Start.

**Requirements:** Windows 10/11 x64, an administrator account, and a supported keyboard profile. Copy, Paste, Undo, and sign-in startup were previously verified on a physical Sun Type 7; other keys and hotplug behavior have not been physically verified.

USBPcap 1.5.4.0 has an [unresolved Windows 11 crash report](https://github.com/desowin/usbpcap/issues/146). The app and installer are unsigned. The original project code still has no selected license; bundled USBPcap retains its upstream signature, matching source, and GPL/BSD licenses.
