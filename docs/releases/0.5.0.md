# Sun Keyboard Tools 0.5.0

## Privilege separation and hardening

- The settings window, profile storage, help, and shortcut injection now run as a normal user. Shortcuts into administrator-level applications are deliberately blocked by Windows.
- A separate elevated capture helper reads USBPcap. Its local connection accepts a bounded keyboard description and returns key events; it cannot execute shortcuts, launch supplied commands, or write supplied paths.
- The helper checks its protected installation location. Startup launches only that installed helper; editing startup requests administrator approval.
- Setup rejects writable or redirected privileged paths, uses an embedded maintenance executable, and no longer writes elevated logs beside downloads.
- USBPcap maintenance checks the exact bundled 1.5.4.0 executables as well as their signature. Other driver versions can be managed through Windows Installed apps.
- Added compiler/linker hardening, protocol regression tests, and bounded profile-line parsing.

Saved mappings and the current USBPcap installation are preserved. UAC must be enabled for the administrator account using the app. This is a defense-in-depth update, not a claim of a complete security audit; see SECURITY.md in the repository.
