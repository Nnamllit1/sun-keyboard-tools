Download **SunKeyboardTools-Setup-0.2.0-x64.exe** below and double-click it. Normal installation, repair, driver maintenance, and uninstall all use graphical windows; no terminal is needed.

- Map the Sun Type 7's extra keys to editable Windows shortcuts.
- Run automatically after sign-in, with tray controls and a key monitor.
- Install or repair the app while preserving profiles and the startup preference.
- Open **Sun Keyboard Tools Setup** from Start to manage the installation.
- Reinstall USBPcap with a guided two-restart flow; setup reopens after the first sign-in.
- Uninstall from Windows Installed apps, keeping saved profiles and optionally removing the shared driver.
- Includes signed USBPcap 1.5.4.0, its matching source archive, and required licenses.

**Requirements:** Windows 10/11 x64 and administrator access. The supplied profile is for the Sun Type 7 (`0430:00a2`). Copy, Paste, Undo, and sign-in startup were verified on a physical Type 7. Other keys and hotplug behavior have not been physically verified.

**Driver compatibility:** USBPcap has an [unresolved Windows 11 crash report](https://github.com/desowin/usbpcap/issues/146). Do not disable Windows security features to load it. Setup never restarts Windows automatically. Reinstalling/removing the driver also affects Wireshark and other USBPcap users.

The original app and installer are unsigned and have no selected source license. USBPcap retains its upstream signatures and GPL/BSD licenses. `SHA256SUMS.txt` verifies the download; checksums do not substitute for code signing.
