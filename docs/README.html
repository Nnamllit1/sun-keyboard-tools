Your Sun keys, useful again.

Sun Keyboard Tools makes the extra keys on a Sun Type 7 USB keyboard run familiar Windows shortcuts. It runs in the notification area, with editable profiles and automatic startup.

Getting started

  1. Run SunKeyboardTools-Setup.exe. Setup installs the app, the signed USBPcap input driver if needed, a Start menu shortcut, and automatic startup for your account.
  2. Restart Windows if setup reports that USBPcap was newly installed. Setup never restarts the computer itself.
  3. Open Sun Keyboard Tools from Start. After a restart it starts in the notification area. Release all keys once, or tap and release an ordinary key, to establish the initial keyboard state.
  4. Select text in an editor and use the keyboard's Copy and Paste keys.

Compatibility: the bundled USBPcap 1.5.4.0 driver is signed, but Windows 11 compatibility is not guaranteed. An unresolved upstream Windows 11 crash report exists. Do not disable Windows driver security to make it load. Copy, Paste, Undo, and automatic startup after a restart have been verified with a physical Type 7 on Windows 11 build 26300. Other default keys and hotplug behavior have not yet been tested on hardware.

Settings

Click the tray icon to open settings. Choose or type a shortcut and click Save shortcuts. Supported modifiers are Ctrl, Alt, Shift, and Win. Follow them with a letter, digit, F1–F24, or a named navigation key such as Enter, Tab, Esc, Home, End, PageUp, PageDown, Delete, Insert, Left, Right, Up, Down, Space, or Backspace. Use Disabled to ignore a key.

Pause remapping temporarily stops capture. Key monitor shows mapped extra-key presses without sending shortcuts. Counts reset when capture restarts. Closing the window keeps the app in the tray; right-click the tray icon and choose Exit to stop it. Pause and monitor mode are temporary; a new launch resumes normal remapping.

Start automatically when I sign in controls a Task Scheduler task for your account. It runs with administrator privileges, without another UAC prompt at each login. Interactive shortcuts start after sign-in, not on the Windows login screen.

Profiles and other keyboards

Profile folder opens %LOCALAPPDATA%\SunKeyboardTools\profiles. Duplicate the Type 7 INI file, then set the actual USB vendor/product IDs, interrupt endpoint, report layout, and HID usage mappings. Restart the app to discover a new file. This decoder supports array-style HID reports; a different report format requires a C++ decoder extension. The included Type 7 profile is the only supplied hardware profile. Connect one matching keyboard at a time.

Profiles are user data and survive upgrades and uninstall. Setup is intended for an administrator account. If you enter a different user's credentials into UAC, settings and startup belong to that administrator account.

Troubleshooting

  • USBPcap is not active: restart after installation. Check Windows Installed apps for USBPcap; do not install it repeatedly.
  • No matching keyboard: check the profile and USB cable. Close Wireshark or USBPcapCMD if they are using the same USB controller.
  • No first press: release the key and try again. The first valid report establishes held-key state after reconnect or settings changes.
  • Skipped shortcut: release physical modifiers and the target shortcut key. Conflicting held modifiers are skipped rather than changing their meaning. Secure desktop, lock screen, and some applications do not accept injected input.
  • Wrong behavior in one program: change that key's shortcut to the one the program uses. Bindings apply globally.

The app observes USB reports and cannot suppress keys Windows already handles. Use profiles for otherwise ignored extra keys. It processes reports in memory, keeps no packet capture or ordinary-key log, and makes no network requests. The USBPcap filter driver itself is installed for the system's USB class.

Removing the app

Use Settings → Apps → Installed apps → Sun Keyboard Tools → Uninstall. This removes the current account's startup task and app files. Other users should disable their own startup tasks first. USBPcap is shared with tools such as Wireshark, so uninstall it separately from Installed apps if you no longer need it, then restart Windows.
